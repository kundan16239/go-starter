# Documentation (`docs/`)

This folder is intended for project documentation, architecture notes, onboarding guides, and any other non-executable resources.

- **Purpose:** Store markdown files, diagrams, and notes related to the project.
- **Guideline:** Do **not** place any code or files that should be executed by the application here.
- **Examples:**
  - `architecture.md` — System design and architecture decisions
  - `onboarding.md` — New developer onboarding instructions
  - `api.md` — API documentation

Feel free to add more documentation files as needed to help future contributors understand and work with the project.
